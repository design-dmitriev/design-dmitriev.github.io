# design-dmitriev.github.io

Сайт-портфолио Алексея Дмитриева. Главная страница — актуальная версия сайта (бывший `/new-site/`).
Старый адрес `/new-site/` перенаправляет на главную.

## Структура

Статический экспорт Next.js (`next build` с `output: "export"`), собирается
из отдельного проекта на локальной машине и заливается сюда как готовые файлы.

- `/` — основной сайт (статический, без сборки: HTML, CSS, JS, JSON)
- `/preview/` — рабочий прототип нового сайта (не финал, доступен для просмотра/ревью)
- `CV_Starlight.pdf` — резюме
