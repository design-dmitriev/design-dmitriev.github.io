# Сайт-портфолио — Алексей Дмитриев

Статический сайт без сборки: HTML + CSS + JS в одном файле, без фреймворков и без шага компиляции.
Публикуется через GitHub Pages.

## Локальный запуск

Открывать `index.html` двойным кликом нельзя: галерея кейсов читает картинки по
относительным путям, а браузер блокирует часть запросов с `file://`. Нужен любой
локальный сервер:

```bash
npx -y serve -l 4173 .
```

Дальше `http://localhost:4173`.

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | Весь сайт: разметка, стили и скрипты одним файлом |
| `assets/portfolio/` | Изображения кейсов, которые открываются в лайтбоксе |
| `CV_Starlight.pdf` | Резюме |
| `ideas_ref/` | Черновики и альтернативные визуальные концепты сайта |
| `archive_oldSite/` | Предыдущая версия сайта (два режима «рабочий/хобби», 3D-барабан годов, GSAP-анимации и т.д.) — оставлена на память, в сборке не участвует |

## Особенности сайта

- Один источник света (`#blob`) следует за курсором по всей странице.
- Звёздное поле (`#starfield`) — отсылка к нику Starlight: звёзды мерцают сами и
  разгораются рядом с курсором.
- Секция «Кейсы» открывает лайтбокс с реальными карточками из `assets/portfolio/`.
- Уважает `prefers-reduced-motion` и упрощается на тач-устройствах (кастомный
  курсор, магнитные кнопки, 3D-наклон и proximity-эффекты отключены).
