# Сайт-портфолио — Алексей Дмитриев

Статический сайт без сборки: HTML + CSS + JS в одном файле, без фреймворков и без шага компиляции.
Публикуется через GitHub Pages.

## Локальный запуск

Открывать `index.html` двойным кликом можно — сайт не читает никаких внешних
файлов по относительным путям. Для полной идентичности с прод-версией (или
если что-то не грузится из `file://`) можно поднять локальный сервер:

```bash
npx -y serve -l 4173 .
```

Дальше `http://localhost:4173`.

## Особенности сайта

- Один источник света (`#blob`) следует за курсором по всей странице.
- Звёздное поле (`#starfield`) — отсылка к нику Starlight: звёзды мерцают сами и
  разгораются рядом с курсором.
- Liquid Glass: карточки и панели — полупрозрачные стеклянные плашки с блик-рамкой,
  которая светится точечно в месте, ближайшем к курсору.
- Плавающая стеклянная навигация вверху едет вместе со скроллом.
- Секция «С чем работаю» — переключатель вкладок (Управление / Продукт / Инструменты).
- Уважает `prefers-reduced-motion` и упрощается на тач-устройствах (кастомный
  курсор, магнитные кнопки, 3D-наклон и proximity-эффекты отключены).
