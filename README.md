# design-dmitriev.github.io

Сайт-портфолио Алексея Дмитриева. Главная страница — актуальная версия сайта (бывший `/new-site/`).
Старый адрес `/new-site/` перенаправляет на главную.

## Навигация

В шапке четыре пункта: «Портфолио», «Проекты», «Обо мне», «Контакты».
«Обо мне» раскрывает результаты, процессы, команду, опыт и условия работы.
Меню закрывается после перехода, при клике снаружи и по Escape.
На телефоне нижняя навигация содержит те же четыре пункта; «Обо мне» ведёт
к результатам и остаётся активным при просмотре последующих разделов об опыте.
Шрифт Zarya ST доступен в разделе «Проекты».

## Структура

Статический экспорт Next.js (`next build` с `output: "export"`), собирается
из отдельного проекта на локальной машине и заливается сюда как готовые файлы.

- `/` — основной сайт (статический, без сборки: HTML, CSS, JS, JSON)
- `/preview/` — рабочий прототип нового сайта (не финал, доступен для просмотра/ревью)
- `CV_Starlight.pdf` — резюме

## Картинки

Новые картинки перед загрузкой сжимаются скриптом `tools/optimize-images.py` (WebP, слайды 900 px, длинные макеты 1080 px).
Описание и примеры запуска: `python3 tools/optimize-images.py`.
