# Сайт-портфолио — Алексей Дмитриев

Статический сайт без сборки: HTML + CSS + JS, без фреймворков и без шага компиляции.
Публикуется через GitHub Pages.

## Локальный запуск

Открывать `index.html` двойным кликом нельзя: галерея читает картинки по относительным
путям, а браузер блокирует часть запросов с `file://`. Нужен любой локальный сервер:

```bash
npx -y serve -l 4173 .
```

Дальше `http://localhost:4173`.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Вся разметка: два режима — рабочий и хобби |
| `styles.css` | Стили целиком |
| `script.js` | Логика: переключение режимов и языка, лайтбокс, звук, пиксельные знаки, таймлайн |
| `scramble_test.js` | Глитч-анимация текста |
| `years-3d.js` | Трёхмерный барабан годов в блоке карьеры |
| `dithr-effect-v2.js` | Частицы в герое — звезда и полумесяц |
| `icons/` | Логотипы площадок и фавиконка |
| `assets/portfolio/` | Изображения работ |
| `cv.html` + `generate_pdf.js` | Исходник резюме и печать его в `CV_Starlight.pdf` |

## Резюме

`CV_Starlight.pdf` собирается из `cv.html`:

```bash
node generate_pdf.js
```

Скрипт печатает страницу через локальный Chrome (`puppeteer-core`), путь к браузеру
задан внутри скрипта.

## Внешние зависимости

Подключаются с CDN, локальных копий нет: GSAP + ScrollTrigger, Lenis, three.js,
SplitType, шрифты Orbitron, IBM Plex Mono и mononoki.

Список модов в режиме «хобби» подтягивается на лету из публичного API Modrinth.

## Особенности, о которых легко забыть

- Звук выключен по умолчанию и включается только кнопкой в шапке; трек не скачивается,
  пока звук не включили.
- Версии в ссылках на `styles.css` и `script.js` (`?v=`) нужно поднимать при правках,
  иначе браузеры отдают файлы из кэша.
- Папка `Обложки/` используется галереей «Соц сети» — это не исходники, удалять нельзя.
