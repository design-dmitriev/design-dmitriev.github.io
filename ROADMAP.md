# Дорожная карта проекта

Живой сайт: https://design-dmitriev.github.io/
Репозиторий: `design-dmitriev/design-dmitriev.github.io`, ветка `main`, деплой — GitHub Pages (автоматически по пушу, иногда с задержкой до ~10 минут — если сайт не обновился, можно подтолкнуть пустым коммитом).

## Что сейчас представляет собой сайт

Одностраничный портфолио-сайт дизайнера маркетплейсов, стилизованный под
терминал/HUD в духе ретро-космической фантастики (зелёный неон, ASCII-арт,
пиксельные значки, CRT-шум, звёздный фон). Два режима: «РАБОЧИЙ» (портфолио
дизайнера) и «ХОББИ» (модостроение для Minecraft).

Технически — чистые HTML/CSS/JS без сборки: `index.html`, `styles.css`,
`script.js`, плюс `years-3d.js` (3D-барабан годов на десктопе) и
`dithr-effect-v2.js` (фоновый 3D-логотип на герое). GSAP + ScrollTrigger для
анимаций, Lenis для плавного скролла, Three.js для 3D-эффектов на десктопе.

### Важные технические конвенции (сложились по ходу сессий)

- **Кэш-бастинг**: `styles.css?v=N` и `script.js?v=N` в `index.html` —
  версию нужно поднимать на единицу при каждой правке соответствующего
  файла, иначе GitHub Pages/браузеры отдают старую версию.
- **Мобильная ветка кода**: почти везде мобильное поведение включается через
  `window.innerWidth <= 768` (JS) и `@media (max-width: 768px)` (CSS) —
  десктоп и мобилка часто различаются по логике, а не только по вёрстке
  (пример: 3D-барабан годов на десктопе — Three.js, на мобилке — плоский
  ASCII-текст тем же шрифтом, что и остальные пиксельные значки).
- **Деплой**: коммит + `git push origin main` → GitHub Pages подхватывает
  сам. Если после пуша долго не обновляется — пустой коммит `git commit
  --allow-empty` подталкивает пересборку.
- **Тестирование**: в части сессий встроенный браузер-инструмент отдавал
  статический снепшот вместо живой страницы (ограничение окружения, не
  сайта) — тогда проверка шла статически (синтаксис, баланс скобок,
  сверка id между JS и HTML) без визуального прогона. Держать в уме при
  следующих правках — доверяй, но проверяй на реальном устройстве.

## Как сайт менялся по сессиям (кратко)

1. UX-полировка десктопа: скролл к описанию по клику на имя, кликабельные
   теги навыков, кнопка закрытия лайтбокса, реверс хронологии карьеры
   (2011→2026), ограничение ширины под Ultrawide/4K.
2. Первая волна адаптива под мобилки: убран pin-эффект геро-секции (не
   помещался контент), почищена шапка, ограничено разрешение фонового
   canvas и оптимизирован hover-эффект на буквах имени.
3. Плотная работа над мобильной версией: читаемые года карьеры (сначала
   3D-рендер, потом переход на плоский ASCII — надёжнее и легче), авто-фит
   имени под ширину экрана, попытка акселерометра (в итоге убрана — не
   даёт стабильного результата, особенно на iPhone без запроса разрешения,
   а запрашивать разрешение решили принципиально не делать), мягкая
   пагинация карточек года при скролле.
4. Чистка кода: убраны мёртвые переменные, задублированный CSS-блок,
   неиспользуемый GSAP Observer-плагин.
5. Мобильный лайтбокс галереи переделан в духе Wildberries: убран зум по
   тапу и боковые стрелки (только свайп), маленькая пиксельная стрелка
   «назад» поверх картинки вместо кнопки на всю ширину, анимация
   растворения между фото при свайпе (длительность зависит от скорости
   свайпа), звук полностью отключён на мобилке (и сама кнопка тоже).
6. Фикс: года карьеры на мобилке подрагивали при скролле — остаток
   мышиного tilt-расчёта делился на `innerHeight`, который сам меняется при
   скролле (схлопывается адресная строка браузера). На мобилке акселерометра
   больше нет, подменять расчёт нечем — теперь на мобилке он просто не
   выполняется, цифры стоят неподвижно.
7. Второй заход на мобильный лайтбокс, ближе к оригиналу WB: поменял
   местами блоки — миниатюры сразу под фото, описание/аналитика ниже (было
   наоборот, описание мешало долистать до миниатюр); добавлен режим
   «только фото» по тапу на картинку — прячет миниатюры и описание,
   вместо стрелки «назад» показывается «[ ЗАКРЫТЬ ]» в стиле сайта
   (моно-шрифт, скобки, как у десктопной кнопки), полностью закрывает
   лайтбокс. В этом режиме — pinch-zoom двумя пальцами (1x–4x) и панорама
   одним пальцем при зуме, без конфликта со свайп-навигацией (жест
   определяется в момент касания). Стрелка «назад» в обычном режиме —
   без круглой подложки, крупнее на 50% (терминальный HUD-стиль, не
   «иконка приложения»). Свайп между фото теперь тянется вживую за
   пальцем (blur/прозрачность/сдвиг меняются непрерывно по ходу
   перетаскивания — как проявление цифр при скролле), а не проигрывает
   готовую анимацию только после отпускания.

8. Фикс: скролл-снап годов карьеры (докрутка до ближайшего года по
   окончании скролла) был включён и на десктопе — на мыши это ощущалось
   как насильственный возврат назад, если пользователь не доскроллил до
   середины перехода. Снап оставлен только для мобилки (там он
   компенсирует неточность пальца), на десктопе `snap` теперь `undefined` —
   колесо мыши достаточно точное само по себе.

15. **Года в 3D-барабане: наконец найдена настоящая причина.** Пользователь

    только ключи `2011 / 2020 / 2022 / 2024 / 2026`. Для отсутствующих ключей
    стоит молчаливый fallback `yearAscii["2026"]` — то есть после смены годов
    на реальные из CV (пункт 12) на экране вместо **2021** и **2023**
    рисовался **2026**. Отсюда и «перепутанные года»: 2011, 2026, 2022, 2026,
    2024. Добавил карты `2021` и `2023` (7×5 сегментов на цифру, шаг 7
    символов — формат существующих карт).

      не было цифры `'3'` (только 0,1,2,4,6), fallback `glyphs['0']` рисовал

      возвращается CSS. Фикс из пункта 13 (текст не течёт на футер) при этом
      сохранён.

    - **3D-каркасные иконки в «// ВЫПОЛНЕННЫЕ_КЕЙСЫ»** — новый файл
      `case-icons-3d.js`. Референс — чайник Юты (1975): каркас без заливки.
      Три модели из примитивов, каждая медленно вращается по Y с лёгким
      покачиванием по X:
      - `ai` — буквы «AI» брусками (две наклонные стойки + перекладина + I);
      - `document` — толстая плита и два смещённых «листа» под ней;

17. Правки по иконкам кейсов:
    - **«AI» заменено на сердце.** Модель — плоский контур из кривых Безье
      (`THREE.Shape`), вытянутый в объём через `ExtrudeGeometry`. Для него
      `EdgesGeometry` вызывается с порогом 18°, а не 1°, как у коробок: на
      скруглённом силуэте каждый сегмент кривой давал бы свою линию и форма
      зарастала штриховкой по всей боковой стенке. С порогом 18° остаются
      обводки лицевой и тыльной граней плюс вертикали на острых углах
      (нижний кончик, верхняя выемка) — сердце читается сразу.
      Исходный контур идёт лопастями вниз, поэтому модель перевёрнута через
      `rotation.z = Math.PI`.
    - **Мобильный фолбэк**: 3D на телефоне не инициализируется, и карточка
      осталась бы со звёздочкой от прежней версии — добавил пиксельный глиф
      `heart` в `GLYPH_MAPS` (script.js), карточка переведена на
      `data-glyph="heart"`.
    - **Все модели крупнее на 20%** (`model.scale.setScalar(1.2)`). Увеличена
      именно модель внутри рамки — сама рамка `.row-icon` осталась 104px.
      Запаса по кадру хватает: самая широкая модель (монитор) в развороте
      занимает ~2.3 юнита при видимых ~3.7, проверил на разных фазах
      вращения — ничего не обрезается.
    - `case-icons-3d.js` → `v=3`, `script.js` → `v=65`.

21. Фикс: иконки визуально «съезжали» в квадратной рамке — заметнее всего у
    асимметричных моделей (тарелка задрана вверх, шаттл с рубкой сверху и
    грузом снизу). Причина: `model.rotation` крутит вокруг локального (0,0,0)
    группы, а её геометрический центр после сборки примитивов почти никогда
    не совпадает с этой точкой — модель вращается не вокруг своей визуальной
    середины, а вокруг случайной точки где-то у себя внутри.
    Чинить через `model.position` нельзя: Object3D применяет позицию в
    мировых координатах уже ПОСЛЕ поворота, так что модель начала бы не
    стоять по центру, а описывать круги вокруг старого центра рамки.
    Правильно — сдвинуть содержимое ДО поворота, в локальном пространстве:
    добавлена `centerPivot()` в `case-icon-models.js`, все дочерние узлы
    модели переносятся во вложенный pivot-`Group`, который сдвигается на
    `-center` (центр из `THREE.Box3().setFromObject`). Обёрнуто вокруг всех
    9 билдеров сразу на экспорте (`centered()`), а не в каждой функции
    отдельно — новые модели автоматически получат туда же.
    - Проверено численно (не на глаз): bounding-box центр всех трёх боевых
      моделей (`chip`, `radar`, `globe`) — ровно `(0, 0, 0)`.
    - `case-icon-models.js` → `v=2`.

23. Вращение иконок кейсов на мобиле — обсуждали, не резать полигоны
    (геометрия и так тривиальна — у самой сложной модели пара сотен
    отрезков, дело было не в этом, а в стоимости трёх отдельных WebGL-
    контекстов), в итоге выбрали вариант «просто CSS-поворот вокруг оси,
    без WebGL вообще»: пиксельный SVG на мобиле крутится через
    `transform: rotateY()` с `perspective` на родителе — GPU-композитор,
    ноль canvas и ноль render-луп. Правило живёт в
    `@media (max-width: 768px)`, отключается на `prefers-reduced-motion`.
    На плоском спрайте `rotateY` не «ломается» на 90°/270° — там на один
    кадр тонкий срез, дальше вращение продолжается (тот же принцип, что у
    CSS card-flip эффектов).
    - Проверено вживую (headless, мобильный viewport): `animationName:
      icon-spin-y` подтверждён на всех трёх SVG, WebGL-канвасов нет; два
      скриншота с разницей в 1с показывают разные фазы поворота.
    - `styles.css` → `v=40`.
