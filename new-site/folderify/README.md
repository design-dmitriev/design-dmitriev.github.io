# Folderify

Плагин Figma: выгрузка выделенных кадров и исходников (.fig, PDF) прямо на Яндекс.Диск и ссылка на результат.

## Установка
1. Скачайте папку `folderify`.
2. В Figma: Plugins → Development → Import plugin from manifest… → выберите `manifest.json`.
3. Запустите плагин, пройдите инструкцию (кнопка «Как это работает» всегда под рукой).

## Как пользоваться
1. Войти через Яндекс и вставить токен.
2. Выбрать или создать папку на Диске.
3. Выделить кадры, выбрать формат и масштаб, нажать «Экспортировать».
4. Для исходников: File → Save local copy, затем загрузить файл, он попадёт в подпапку Sources.

Сеть: только cloud-api.yandex.net и *.yandex.net. Токен хранится в clientStorage Figma на вашем компьютере.
